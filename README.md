# HOMOVERSE

`verseslots/` is the walking-mall prototype: an open-air ring of shops around a dusk plaza, enterable interiors, a Golden Hour demo slot, and Homo Bingo in the Members' Lounge (demo daubers only). Demo credits are not HOMO tokens. HOMOV membership, when used, is a read-only Base balance check. Location is optional. Graphics quality is High, Medium, or Low (curved façades, dusk HDRI, and PBR textures; still stylized, not a photoreal city).

```bash
cd verseslots && npm install && npm test && npm run dev
```

A world where the House of HOMO has a door you can walk through.
